# 决策日志

> 作用：记录已经明确的选择、尚未明确的选择及复审条件，防止后续任务把假设误当成事实。日期均为决策记录日期，不等于功能上线日期。

## 状态说明

- `已定`：后续工作默认遵循；改变时追加新决策，不静默覆盖。
- `已替代`：历史决策保留，但其当前效力已被更晚的决策明确替代。
- `暂定`：可用于推进MVP，但在指定节点需要复审。
- `待定`：不得擅自替用户作最终选择。
- `否决`：当前阶段明确不做；满足复审条件后可重新讨论。
